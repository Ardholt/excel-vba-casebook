# Files and visual assets

The branch exports, code, overview and checked output belong to this case and use anonymous codes. The repository licence applies to the case source.

Sheet images are renders of the linked workbooks. `scripts/proof_media.py` builds the opening animation and its still image from the measured refresh events, file report and checked table entry. The animation replays the macro invocation log, retimed for reading; it is not an application screen recording. The proof uses DejaVu Sans and DejaVu Sans Mono under the DejaVu font licence. Font binaries are not distributed here. See [the source and timing record](evidence/proof-media.json).

The macro workbook is packaged with pyOpenVBA and its embedded workbook template under the retained [MIT licence](evidence/PYOPENVBA-LICENSE.txt). See [execution scope](evidence/runtime.json). No borrowed business data or third-party photographs are included.
