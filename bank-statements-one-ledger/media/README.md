# Before and after

The hero combines two actual worksheet renders from the statement overview and checked ledger. The panels are enlarged to a common width and padded below to retain the complete selected cell range. No statement values are altered. [Source image records](../evidence/images.json) and [hero capture record](../evidence/hero.json).

Typography uses Inter SemiBold, Instrument Serif and JetBrains Mono from the shared page style, under the SIL Open Font Licence. The font files are not distributed here.
