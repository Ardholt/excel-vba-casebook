# Visual assets

Workbook sheet captures and invoice views come from the files in this case. The hero is a compact, typeset extract of source invoice INV-0017 beside its ledger entry, followed by the reconciliation arithmetic. It is generated by `scripts/render_hero.py` from `input/input.xlsx` and the checked output files; it is not a screenshot of an invoice document. `evidence/hero-proof.json` records the rows, values and source hashes. No third-party photographs or invoice artwork are reused.

The hero uses DejaVu Sans from the container's installed fonts (DejaVu/Bitstream Vera font licence). Only rendered text is included here; font binaries are not distributed. The workbook requests Carlito from the container's installed fonts. The captured sheet images are the actual LibreOffice rendering of those workbooks.

PNG metadata is stripped. Every published image has been visually inspected. The page previews show the local rendering of the README; they are not evidence of publication.
