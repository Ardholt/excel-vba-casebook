# Visual assets

Workbook sheet captures and invoice views come from the files in this case. The hero follows the shared Ardholt casebook template. No third-party photographs or invoice artwork are reused.

The hero uses Inter (Inter Project Authors), Instrument Serif (Instrument Serif Project Authors) and JetBrains Mono (JetBrains Mono Project Authors), all under the SIL Open Font License. Only rendered text is included here; font binaries are not distributed. The workbook requests Carlito from the container's installed fonts. The captured sheet images are the actual LibreOffice rendering of those workbooks.

PNG metadata is stripped. Every published image has been visually inspected. The page previews show the local rendering of the README; they are not evidence of publication.
