# Image sources

The hero is a typeset proof graphic from the saved button-run workbook and action record, not an application screenshot. [Hero evidence](../evidence/hero.json) identifies every displayed month and category and the source file. It uses the container's DejaVu Sans font; no font files or stock images are shipped. The images in `../images/` are LibreOffice renders of saved workbook regions.

The [refresh replay](refresh.gif) sequences actual saved worksheet renders from the before, after and repeat button runs. [Frame sources](../evidence/refresh-demo.json) identify each workbook and action.
