# Container and dependencies

Run `./run.sh` from this case in a clone or extracted download of the full repository. Prerequisite: a running Docker engine and permission to build and run containers. No local Python or Office installation is required for the reference run. The first build may need internet access to obtain the shared image dependencies; the case container runs with networking disabled.

The shared build definition is [`../docker/Dockerfile`](../docker/Dockerfile), using Ubuntu 24.04 and the repository's pinned dependencies. The wrapper builds tag `excel-vba-casebook`, then mounts the case and input read-only and the requested output directory for writing. The exercised Python package versions are listed in [requirements.lock](requirements.lock). See [runtime evidence](evidence/runtime.json) for versions actually exercised. Docker invocation and desktop Excel execution are separate acceptance steps; the default command runs the Python reference tests. The separate `python3 scripts/run_vba.py` command executes the supplied macro workbook in LibreOffice and checks its saved outputs. It uses the included fixed tabs and additional sales rows; it does not install or click the Excel button.

The scripts use Python, openpyxl, XlsxWriter, pytest and LibreOffice through the repository's `xlrecalc` helper. Pillow is used only for image metadata cleanup. The repository's `xlrender` helper renders the workbook with macros disabled. No data download is required. The optional macro-packaging step uses the project template covered by [its licence](vba/PACKAGING-LICENSE.txt). [Hero lettering](media/ATTRIBUTION.md) uses the shared page style; its font files are not shipped. [Preview evidence](evidence/page-source.json) documents the remote badge image omission in the offline page capture.
